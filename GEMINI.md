# StackForge — Product & Engineering Brief 🚀

## 🎯 The Vision
StackForge is an AI-powered platform designed to solve the most critical problem in modern Cloud and DevOps hiring: **The Skills Gap.** 

Candidates often have generic portfolios, while top-tier companies require proof of mastery in complex, production-grade workflows. StackForge bridges this gap by turning job descriptions into precision-engineered project roadmaps.

---

## 🏗️ The Four Pillars of StackForge

### 1. Job Description Analyser (The "Gap" Identifier)
- **What it does**: Uses Google Gemini 1.5 Flash to deconstruct complex job postings.
- **The Value**: It extracts mandatory vs. preferred skills and identifies exactly where a candidate's portfolio is lacking based on the current market.

### 2. Project Recommender (The Strategic Planner)
- **What it does**: Generates 3-5 high-impact, ranked project ideas tailored to a specific dream job.
- **The Value**: Focuses effort on projects that demonstrate the highest ROI for hiring managers.

### 3. Implementation Plan Generator (The Technical Architect)
- **What it does**: Produces complete technical blueprints—architecture, file structures, and exact CLI commands (Terraform, Docker, Kubectl).
- **The Value**: Moves users from "idea" to "execution" with senior-level best practices built-in.

### 4. Project Upgrader (The Production-Ready Filter)
- **What it does**: Critiques existing projects and provides a checklist to move them from "student-grade" to "production-grade" (Monitoring, Security, HA, SLOs).
- **The Value**: Teaches candidates how to think like a Senior Platform Engineer.

---

## 🛠️ The Technical "Flex" (Engineering Highlights)

To build this, we implemented a sophisticated, multi-layer cloud architecture:

- **Frontend**: Next.js 14 (App Router) with Tailwind CSS. Optimized for high-performance and a modern, "senior engineer" aesthetic.
- **Backend**: Python FastAPI. A high-performance, RESTful API designed for scale and AI orchestration.
- **AI Layer**: Google Gemini 1.5 Flash. Custom prompt engineering to deliver professional, technically accurate DevOps guidance.
- **Database & Auth**: Supabase (PostgreSQL). Implemented Row Level Security (RLS) and automated PL/pgSQL triggers for user profile management.
- **Infrastructure as Code (IaC)**: Terraform. Multi-cloud ready architecture with GCP configurations and Artifact Registry integration.
- **DevOps/CI/CD**: GitHub Actions. Automated deployment pipelines to Render (Backend) and Vercel (Frontend).
